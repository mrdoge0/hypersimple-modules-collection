# Hyper Simple Modules Collection v2.1

### New modules
* **App Blacklister**: Blacklist FSA bloatware with ease using a blacklist file.
* **Introduce Blurs**: Exact reverse of Nuke Blurs.

### App Blacklister
* Please note that it still has the module ID of the legacy APK Liberator, so migration from it is as simple as a module upgrade (and Android Developer Verifier *is* on the default blacklist).

### Enable MD3 Expressive Design
* Added a new check to see if the Android version has MD3E or not.
