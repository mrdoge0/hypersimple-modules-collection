# Hyper simple modules collection
It's as self explanatory as it can get :3

# Modules here.
* **APK Liberator**: A hyper simple daemon module to keep your Android device open via basically banning the installation of Android Developer Verifier out of your device.
* **Enable M3 Expressive Design**: A hyper simple module to enable Material 3 Expressive on Android 16 QPR0, or fix some settings menus not being Expressive design on QPR1+.
* **Fix GSI Identity Crisis**: A Hyper simple module to fix device name in GSIs. You'll see your actual device model instead of things like 'TrebleDroid vanilla' or 'AOSP on ARM64'.
* **NDot Kasane Teto Bootanmiaton**: NDot version of the pixel art Teto animation from the first scene of Machine Love's MV. Built for and tested in the Phone (1) (Spacewar), and may or may not work properly in other devices.
* **Nuke Blurs**: A hyper simple module to disable blurring effects on low end devices.
* **Optimize SurfaceFlinger**: A hyper simple module to do some SurfaceFlinger optimizations. Doesn't do that much change, it more is like placebo effect, but nice to have.
* **Skia Vulkan Renderer**: A hyper simple module to enforce Vulkan renderer. Tested on Spacewar.
* **Unspoof my LineageOS**: A hyper simple module to unspoof the fingerprints and descriptions for LineageOS builds. IDK anybody would want this, but...

# How to install them?
Download them (preferably download v2 ones since they now have updateJson support), install them like any other module, reboot.
